DiskFinch support

Prerelease: App Store submission and release are not complete. DiskFinch is not yet available to download from the App Store.

DiskFinch makes Xcode build cleanup simple. Inspect folders you choose, review exact generated build folders, and move eligible folders to Trash with explicit confirmation. Scanning and review are free. A one-time App Store purchase unlocks eligible moves to Trash; it never starts cleanup automatically.

Choose and review a folder

Grant access with the macOS folder picker. For generated Xcode build files, select one project folder directly inside ~/Library/Developer/Xcode/DerivedData. Selecting a parent or an unrelated folder grants inspection only. Installer and simulator cleanup are excluded.

Close Xcode and build or indexing processes. Scan the selected folder, select an eligible result, and review its exact path and consequences. Confirm only if you can recreate its generated output. An incomplete or stopped scan cannot authorize cleanup.

Restore an existing unlock

Choose Restore purchases using the Apple Account that bought the unlock. Restore does not buy the product or run cleanup. An offline, pending, cancelled or unverified transaction cannot unlock cleanup. After purchasing or restoring, scan and review again. An unlock cannot bypass permissions or safety checks.

For billing or refund requests, use Apple’s purchase support. Apple decides refund eligibility.

Recover a Trash move

Choose Show in Trash in the recorded result. In Finder, use Put Back if offered. Otherwise move that exact item to its original location shown by DiskFinch. If an item now exists at that location, stop and compare before restoring; do not overwrite newer files. Moving to Trash does not itself free occupied storage. DiskFinch does not empty Trash. Recovery ends after the item is emptied; Trash is not a backup.

Permissions and stopped results

If access expires or the folder changes, choose the same folder again and rescan. Forget removes DiskFinch’s saved permission and current scan/review, but existing cleanup records remain.

If a result is uncertain, inspect the original path and any recorded Trash destination before retrying. DiskFinch never replays an operation automatically. Preserve an unreadable or unsaved journal. A known unsaved destination may exist only in the current app session; inspect it before quitting. Do not delete the journal to bypass a refusal.

Contact support

Use the DiskFinch support issue tracker. This public support route requires a GitHub account. Describe your macOS version, app version, steps and the visible error. Issues are public: never include private file contents, unredacted paths, Apple Account details or payment information. No response-time guarantee is made.

The app cannot guarantee a particular storage saving. Volume readings include unrelated writes and are not savings attributed to a Trash move.
